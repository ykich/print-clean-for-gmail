日本語

Print Clean for Gmail（以下「本拡張機能」）は、利用者のデータを収集しません。

  • 本拡張機能は、個人情報・メールの内容・メールアドレス・閲覧履歴を含め、いかなるデータも収集・送信しません。
  • 本拡張機能は外部サーバーと通信しません。開発者がデータを受け取ることはありません。
  • 本拡張機能が保存するのは、印刷にどの項目を表示するかという設定（5 項目それぞれのオン・オフ）だけです。この設定は Chrome の chrome.storage.sync に保存されます。
  • 利用者が Chrome の同期を有効にしている場合、この設定は Chrome の機能によって利用者の Google アカウント経由で他の端末と同期されることがあります。この同期は Chrome（Google）が行うもので、開発者はその内容にアクセスできません。
  • データを第三者に販売・譲渡することはありません。

本拡張機能は Google の公式製品ではなく、Google LLC とは提携・承認の関係にありません。Gmail は Google LLC の商標です。

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

English

Print Clean for Gmail ("the extension") does not collect any user data.

  • The extension does not collect or transmit any data, including personal information, message content, email addresses and browsing history.
  • The extension does not communicate with any external server. The developer receives no data.
  • The only thing the extension stores is which items to show in the printout (an on/off value for each of the five items). This setting is stored with Chrome's chrome.storage.sync.
  • If you have Chrome sync turned on, Chrome may sync this setting to your other devices through your Google Account. This sync is performed by Chrome (Google), and the developer has no access to it.
  • No data is sold or transferred to third parties.

The extension is not an official Google product and is not affiliated with or endorsed by Google LLC. Gmail is a trademark of Google LLC.

If this policy changes, this page will be updated along with the "Last updated" date.
