Print Clean for Gmail

Gmail の「すべて印刷」画面で、アカウント欄・件名・送信元・日時・宛先を隠し、本文だけを印刷できるようにする Chrome 拡張機能です。

A Chrome extension that hides the account bar, subject, sender, date and recipients in Gmail's print view, so only the message body is printed.

  • データを収集・送信しません / No data collection
  • 権限は storage のみ。動作するのは Gmail の印刷画面だけですが、インストール時に「mail.google.com のデータの読み取りと変更」と表示されます / Only the storage permission. Chrome still shows a "mail.google.com" access warning because the script runs on Gmail's print view.
